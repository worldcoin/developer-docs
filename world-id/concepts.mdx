World ID is designed for straightforward integration. This page covers only the core concepts most teams need before shipping.

## Credentials

A credential is a verifiable statement about a user. In World ID, credentials are used to prove properties like humanness without revealing the user's identity.

The table below is intentionally a placeholder and will be expanded:

| Credential | IDKit / protocol label | Notes |
| :--- | :--- | :--- |
| Proof Of Human, Orb credential | `orb` | High-assurance proof-of-human credential. |
| Passport | `document` / `secure_document` | Document-based credential. |
| MNC in Japan | `secure_document` | Treated as a secure document credential. |
| eID | `secure_document` | Treated as a secure document credential. |

## Presentations

A presentation is when a user proves something about their credential to an application, also called a Relying Party (RP).

In practice:

1. The application (RP) requests a proof for an `action`.
2. The Authenticator generates a ZKP.
3. The RP verifies the proof and uses the nullifier to enforce one-time actions when needed.

## Vocabulary

Some terms are used throughout the World ID documentation. Here are a few of the most important ones:

- **World ID**: A user's self-custodial identity in the World ID protocol.
- **Relying Party (RP)**: The application requesting and verifying World ID proofs.
- **Authenticator**: Software or hardware that acts on behalf of the user to generate protocol proofs.
- **Credential**: A signed attestation used as input to proof generation.
- **Presentation / Proof**: The payload a user submits to an RP to prove a statement.
- **Zero-Knowledge Proof (ZKP)**: A proof that a statement is true without revealing the underlying private data.
- **Nullifier**: A one-time identifier derived from user + RP + action, used to prevent duplicate claims without identifying the user.
- **Action**: RP-defined context that scopes what the user is proving uniqueness for.
- **`app_id`**: Your application identifier from the [Developer Portal][developer-portal].
- **Signal**: App-provided data that is cryptographically bound into the proof.
