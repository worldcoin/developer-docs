Use this page to track World ID features that are limited to legacy protocol
flows and the current migration guidance for new integrations.

## Device verification

**Status:** World ID 3.0 legacy only

`deviceLegacy()` requests a World ID 3.0 Device proof for existing
integrations. World ID 4.0 does not have a Device preset. New integrations
should choose a current credential from the
[credential guide](/world-id/idkit/credentials).
