The World Docs MCP gives your AI assistant direct access to World documentation through the [Model Context Protocol](https://modelcontextprotocol.io/).

Use it when you want Claude, Codex, Cursor, VS Code, or another MCP client to search current World docs while you build.

## Endpoint

```text
https://docs.world.org/mcp
```

The docs MCP does not require authentication.

## Connect your client

<Tabs>
  <Tab title="Claude Code">
    ```bash
    claude mcp add --transport http --scope project world-docs https://docs.world.org/mcp
    ```
  </Tab>
  <Tab title="Codex">
    ```bash
    codex mcp add world-docs -- npx -y mcp-remote https://docs.world.org/mcp --transport http-only
    ```
  </Tab>
  <Tab title="Cursor">
    Add this to `.cursor/mcp.json`:

    ```json
    {
      "mcpServers": {
        "world-docs": {
          "url": "https://docs.world.org/mcp"
        }
      }
    }
    ```
  </Tab>
  <Tab title="VS Code">
    Add this to `.vscode/mcp.json`:

    ```json
    {
      "servers": {
        "world-docs": {
          "type": "http",
          "url": "https://docs.world.org/mcp"
        }
      }
    }
    ```
  </Tab>
</Tabs>

## Available tools

| Tool | Purpose |
| --- | --- |
| `search_world_documentation` | Find relevant guides, examples, and API references, with links to the source pages. |
| `query_docs_filesystem_world_documentation` | Search exact terms, explore the documentation tree, and read complete pages or OpenAPI specs. |
| `submit_feedback` | Report incorrect, outdated, or incomplete documentation to the docs team. |

Start with search to find the relevant pages. When you need the full guide, use the filesystem tool to read its discovered `.mdx` path with `head` or `cat`. Use `rg` for exact terms and `tree / -L 2` to explore available paths.

The filesystem is a read-only view of published documentation and API specs. Its commands do not run on your computer or access your local files. Feedback is the only tool that submits information to the docs team.

## When to use it

Use the docs MCP to look up public integration instructions. For app management in the World developer portal, use the [Developer Portal MCP](/model-context-protocol/developer-portal).

World ID Auth has separate connections. Its [developer MCP](/agent-pass/build-with-a-coding-agent) manages Auth applications after developer authorization. Its [user MCP](/agent-pass/use-world-id-with-your-agent) accesses authorized World ID account capabilities after user sign-in and consent. Reading documentation through World Docs MCP grants neither connection's permissions.
