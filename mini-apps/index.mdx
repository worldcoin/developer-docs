Mini apps enable third-party developers to create native-like applications within World Money.
Best for small and medium sized developers who want access to a distribution channel of millions of users.
Build with smart contracts, World ID, and the wallet in World Money.

World Money provides wallets and payments. The separate
[World ID app](https://world.org/world-id-app) manages identity credentials,
proofs, and authentication, and also hosts identity Mini Apps.

## How it Works

Mini apps are web applications running inside World Money via webview. Using the MiniKit SDK, these applications can become
native-like and interact with the World ecosystem.
