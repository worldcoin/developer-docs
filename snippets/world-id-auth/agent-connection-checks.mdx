For app management, request only `developer-portal:manage` on `/mcp/developer`.
Keep that connection separate from the user MCP's `world-id:read` permission.
If tools are missing, refresh the existing connection before adding one. Start a
new session if the host requires it. Stop after cancelled or failed sign-in and
report the result.
