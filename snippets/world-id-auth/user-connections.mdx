## Disconnect an agent

### 1. Choose the connection

Open [Your connections](https://auth.world.org/mcp/connections) for an agent
connected to your World ID account. Developer tools use a separate Google
portal connection at
[Portal connections](https://auth.world.org/portal/mcp/connections).

### 2. Revoke access

Revoke the intended connection. User and developer connections can be revoked
independently. Signing out of the website alone does not disconnect an agent.

### 3. Understand what changes

The revoked user connection can no longer read content that requires
authenticated access. Reading that content again requires new authorization.
Public benefit listings remain available. Partner applications manage their
own sessions and permissions.
